# Tea Atlas

Локальный прототип: фото → выделение надписи → OCR → проверка текста → кандидаты → карточка → полка, желания, личный отзыв.

## Состояние на 16 сентября 2026

- Настоящий локальный OCR латиницы: Tesseract.js 7, модель eng включена. Фото поступает только серверу 127.0.0.1, обрабатывается в памяти, не записывается и не отправляется внешнему API.
- Фото JPEG/PNG/WebP до 10 МБ / 25 Мп, рамка области чтения, редактирование результата. Два прохода OCR с небольшим поворотом; результат может содержать мусор и повторы.
- Пример Bamboo Spring открывается с заранее выбранной областью надписи. Это не автоматическое обнаружение этикетки. На полном мятом фото без обрезки распознавание пока слабое.
- 8 реальных выпусков The Essence of Tea: шэны, улуны, белый и красный чай; есть белый чай разных лет. Поля проверены по публичному каталогу продавца. Источник указан в каждой карточке. Фото есть только у Bamboo Spring.
- Каталог с фильтром типов, консервативный поиск по названию, году и raw/shu. Это поиск совпадений, не проверка подлинности.
- Полка, «Хочу попробовать», личная оценка 1–5, заметка, JSON-экспорт. Старые записи версии 1 читаются с пустым списком желаний. Хранение в localStorage; аккаунтов, синхронизации, общего рейтинга и импорта пока нет.

## Проверено

13 автоматических проверок: реальное OCR обрезанного пользовательского фото и поиск по результату, повреждённое изображение, неверный год/тип, хранение и миграция старого формата.
В браузере: образец → OCR → найденный выпуск → карточка; желания после перезагрузки; фильтр белого чая с двумя годами. Тестовое добавление в желания отменено. Новые произвольные обёртки и китайские надписи ещё не проверены.

## Запуск

Из этой папки: node server.mjs . Открыть http://127.0.0.1:4173/ .
Зависимости уже установлены; при переносе выполнить npm ci. После установки интернет для OCR не требуется. Модель: vendor/lang/eng.traineddata.gz.
Тесты: node --test tests/*.test.mjs
